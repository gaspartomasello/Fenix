# Objetos del juego

Lista de todos los objetos (240), con los mismos grupos que la ventana `/objetos` del administrador del juego. La clave sirve para `/objeto clave [cantidad]`.

Se genera desde el catálogo; si se agregan objetos, hay que regenerarla.
